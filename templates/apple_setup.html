Set up Apple Translate

Apple Translate runs through macOS Shortcuts — you need to create 1–2 Shortcuts that the app will invoke.

Requirements: macOS 14.4 or later (with Thai support) — open System Settings → Translation → Languages and download the language packs you need (Japanese, Thai, English, etc.) for offline use.

Create a Shortcut for translating to Thai

  1. Open the Shortcuts app (Spotlight: Cmd+Space → type "Shortcuts")
  2. Click + in the top-right to create a new Shortcut
  3. Search for the action "Translate Text" and drag it onto the canvas
  4. Configure the action:
    • From: Detect Language
    • To: Thai
  5. Add a "Get Variable" action, or click the Translate Text output, to set it as the Shortcut output
  6. Name the Shortcut exactly: {{ sh_th }} (no extra spaces)
  7. Click Done in the top-right

(Optional) Create another Shortcut for English

  1. Repeat the steps above and change To: to English
  2. Name it: {{ sh_en }}

(Optional) Create another Shortcut for Japanese

  1. Repeat the steps above and change To: to Japanese
  2. Name it: {{ sh_ja }}

(Optional) Create another Shortcut for Vietnamese

  1. Repeat the steps above and change To: to Vietnamese
  2. Name it: {{ sh_vi }}

Test from Terminal

echo "ブレザーとは" | shortcuts run "{{ sh_th }}"

If a Thai translation comes out, you're ready to go.

Verify in the app

Once the Shortcut is ready, pick Apple Translate from the engine dropdown in the Compare tab — the app will invoke this Shortcut every time you click translate.
