🍎 ตั้งค่า Apple Translate

Apple Translate ทำงานผ่าน macOS Shortcuts — คุณต้องสร้าง Shortcut 1–2 ตัว ที่ระบบจะเรียกใช้

ข้อกำหนด: macOS 14.4 ขึ้นไป (มีภาษาไทย) — เปิด System Settings → Translation → Languages แล้วดาวน์โหลด pack ของภาษาที่ต้องการ (Japanese, Thai, English ฯลฯ) สำหรับใช้แบบ offline

ขั้นตอนสร้าง Shortcut สำหรับแปลเป็นไทย

  1. เปิดแอป Shortcuts (ค้นด้วย Spotlight: Cmd+Space → พิมพ์ "Shortcuts")
  2. กดปุ่ม + ที่มุมบนขวา เพื่อสร้าง Shortcut ใหม่
  3. ในช่อง action ค้นหา "Translate Text" แล้วลากมาวางในกระดานทำงาน
  4. ตั้งค่า action:
    • From: Detect Language
    • To: ไทย (Thai)
  5. เพิ่ม action "Get Variable" หรือคลิก output ของ Translate Text → ตั้งให้เป็น output ของ Shortcut
  6. ตั้งชื่อ Shortcut เป็น: {{ sh_th }} (ต้องตรงเป๊ะ ไม่มีเว้นวรรค)
  7. กด Done มุมขวาบน

(ออปชัน) สร้างอีกตัวสำหรับแปลเป็นอังกฤษ

  1. ทำซ้ำขั้นตอนข้างบน เปลี่ยน To: เป็น English
  2. ตั้งชื่อเป็น: {{ sh_en }}

ทดสอบจาก Terminal

echo "ブレザーとは" | shortcuts run "{{ sh_th }}"

ถ้ามีคำแปลออกมาเป็นภาษาไทย แสดงว่าพร้อมใช้งาน

ตรวจสอบจากแอป

เมื่อ Shortcut พร้อมแล้ว เลือก 🍎 Apple Translate จาก dropdown engine ในหน้า Compare ของแอปนี้ — ระบบจะเรียกใช้ Shortcut นี้ทุกครั้งที่กดแปล
